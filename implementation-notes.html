Image Shrink Implementation Notes

Implemented scripts/image-shrink, a local Bash CLI for shrinking JPEG, PNG, WebP, and HEIC/HEIF still images to a measured size limit, with interactive use through cmds. Updated the README, Brewfile, doctor diagnostics, and CI dependencies.

Design Decisions

AreaDecisionReason
Defaults500 KB; preserve format; create a sibling .small file.Matches the reviewed design and preserves originals.
Quality boundsSearch encoder quality 60–90 before reducing dimensions; stop at a 320-pixel longest edge, or the starting edge if smaller.Predictable bounds instead of silently producing a tiny, heavily degraded image. An explicit smaller maximum edge is respected.
UnitsKB/MB are decimal; KiB/MiB are binary. Fractional sizes are rounded down to whole bytes.Upload limits should be unambiguous and never exceeded.
Output formatAn explicit output extension selects the format; conflicting --format is an error.File contents and extension must agree.
Output publicationUse the system link utility to publish a completed, verified candidate atomically on the output filesystem.Unlike ln, it treats the destination as an exact path, so a concurrent directory or symlink cannot redirect the output. Existing paths are never replaced.
Interactive image pickerPrefer fzf with live search, arrow/Tab navigation, Enter to select/open, parent-directory navigation, and Esc cancellation. List supported images and directories, including hidden entries. Offer manual path entry and retain Readline when fzf is absent.Improves selection without adding a language runtime or a new dependency to the Brewfile. Filenames are passed as data, never shell commands; user fzf default options are isolated so multi-selection or custom execute bindings cannot change the picker contract.

Deviations

None identified.

Tradeoffs

AreaChoiceReason
BackendImageMagick, with Homebrew's libheif dependency.A single image-processing backend for all reviewed formats.
Repeated attemptsDecode and orient once into a private, lossless MIFF working image; derive every attempt from it.Avoid repeated HEIC decoding and cumulative lossy recompression.
PNGLossless encoding at each resolution; resize if needed.No silent palette reduction or format conversion.
iPhone featuresPrimary still image only; no promise to retain Live Photo video, depth data, or HDR gain maps.The tool prepares small standalone images, and the original is retained.

Open Questions

None blocking implementation. The quality and dimension floors are documented defaults that can be revised after use.

Validation

  • Installed ImageMagick and ShellCheck; verified HEIC reading and writing with the installed backend.
  • All shell syntax checks, Zsh syntax checks, ShellCheck at warning severity, and whitespace checks passed.
  • All eleven regression suites passed with macOS Bash before publishing the PR. Azure DevOps tests used GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_NOSYSTEM=1 to isolate fixture profiles from machine-global Git configuration; the initial run with machine-global settings failed its HTTPS context assertion. No unrelated Azure DevOps code was changed.
  • The new image suite uses generated images and a temporary home. It covers measured limits, quality-only compression, resizing bounds, PNG/WebP transparency, HEIC input/output and conversion, EXIF orientation, primary still selection, literal special-character paths, existing-path preservation, concurrent publication, encoder failure, interruption cleanup, and interactive discovery through cmds.
  • Readline completion is exercised through pseudo-terminals with macOS Bash: unique prefixes, empty-prompt candidate listing, ambiguous prefixes, directory traversal, absolute paths, spaces, quotes, backslashes, and literal command-substitution characters. Tests cover direct CLI use and cmds, with an isolated input configuration.
  • The fzf picker has a separate regression suite using real fzf in controlling pseudo-terminals. It covers live filtering, arrows, Tab/Shift-Tab, directory/parent navigation, selection through cmds, hidden images, unsupported-file filtering, manual paths, fallback without fzf, cancellation, picker failure, unusual filenames, and isolation from fzf default options. Terminal access was blocked inside the local sandbox; these fixture-only tests passed outside it. CI installs fzf for this coverage.
  • A generated JPEG shrank from 1,849,513 bytes to 118,873 bytes for a 120 KB target. HEIC-to-JPEG/WebP conversion and transparent HEIC output also passed real-backend smoke checks.
  • Installer and doctor were exercised through temporary fixtures; the real home configuration and credentials were not modified.

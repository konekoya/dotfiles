# Git

The default identity comes from `~/.gitconfig.local`; optional `includeIf` rules select `~/.gitconfig.work` for matching repositories. `config-git` writes a manual per-repository identity override. See [Git configuration](../../README.md#git-config) and [config-git](../../README.md#config-git).

Check repository and worktree state before changes. [sync-branch](../../README.md#sync-branch) and [track-branch](../../README.md#track-branch) document the available branch helpers and their worktree protections. Follow user instructions and obtain authorization for destructive operations.
